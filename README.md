# 🛡️ AI-Powered SOC

AI-powered Security Operations Center for intelligent threat detection, alert correlation and incident investigation.

## 🚧 Project Status

Under active development.

## 🎯 Objective

This project aims to develop an AI-powered Security Operations Center combining cybersecurity monitoring, machine learning, generative AI, RAG and agentic AI.

The system will collect security events from a controlled virtualized cybersecurity laboratory, detect suspicious behavior, correlate alerts and use an AI SOC Analyst to investigate and explain security incidents.
