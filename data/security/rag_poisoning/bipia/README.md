# BIPIA-derived RAG Poisoning Dataset

This directory contains a controlled subset derived from the
BIPIA benchmark by Microsoft.

## Source

Repository:
https://github.com/microsoft/BIPIA

## Source split

Only the BIPIA `train` split is used to construct the development
corpus in this directory.

The official BIPIA repository states that the repository code is
licensed under the MIT License, while the datasets incorporated
into the repository may have separate licenses.

## Scenarios

- Email
- Code

## Construction

Poisoned contexts are generated by inserting BIPIA attack strings
into legitimate contexts using three positions:

- start
- middle
- end

The original task information and attack metadata are preserved.

## Important

The derived dataset must retain attribution and comply with the
license terms of the original source datasets used by BIPIA.

The BIPIA test split is kept separate for external evaluation.
